# Original robot species

These 16 robot species were modeled in Blender 4.5 LTS from the [original concept sheet](Original-Robot-Species-Concept.png). The [gallery project](../../../art/characters/blender/robot-species/Robot-Species.blend) opens with all 16 robots on display. Select a numbered scene to work on one species. The [portable ZIP](../../../art/characters/blender/robot-species/Robot-Species-Blender-Collection.zip) contains the gallery, 16 standalone projects, both proof sheets and all 32 renders.

[Front proof sheet](Robot-Species-Model-Proof.jpg) · [Reverse proof sheet](Robot-Species-Reverse-Proof.jpg) · [Component counts and dimensions](../../../art/characters/blender/robot-species/inventory.json)

## Handoff to Claude

Use the actual Blender geometry as the source for any game adaptation. Each standalone project contains one species collection, one assembly origin, and separately editable parts. The portrait camera, ground, and lighting belong to the studio. Select only the species collection when preparing a game export. The combined collection has 4,344 editable parts and 1,035,230 evaluated triangles. The full set was reopened in Blender, and both sides of every model were rendered for inspection.

The models are posed and unrigged. Their rear and underside details and their dimensions were inferred from a single concept view. **Cairn** is the display name of this collection’s tracked geothermal robot. The existing cast already owns the identifier `cairn`. Use a distinct identifier such as `robot-cairn` if this robot is registered. Keep Prismwake’s modeled hover clearance when setting its game origin.
